# Third-party model licenses

Local3D's MIT license covers its original code and documentation. Provider code and weights are installed separately under their upstream terms. Check the individual terms before redistributing a provider, weights or model outputs.

| Component | Upstream license and access |
| --- | --- |
| Stable Fast 3D MLX port and weights | Stability AI Community License. The port includes a “Powered by Stability AI” notice. The official checkpoint requires acceptance in Hugging Face. [Port notice](https://github.com/bahaehmimdi/stable-fast-3d-mlx/blob/ac426cda2f50f5b31ed3818670ee2d426decee22/NOTICE.md) · [Code license](https://github.com/Stability-AI/stable-fast-3d/blob/main/LICENSE.md) · [Checkpoint](https://huggingface.co/stabilityai/stable-fast-3d) |

[Port](https://github.com/lyonsno/trellis2mlx/blob/449bfbc011401fe03d684a01f0b1068bfe8f6ceb/LICENSE) · [TRELLIS.2 4B](https://huggingface.co/microsoft/TRELLIS.2-4B) · [TRELLIS Image Large](https://huggingface.co/microsoft/TRELLIS-image-large) |
| DINOv3 ViT-L/16 | Meta DINOv3 license with separate gated access. [License](https://huggingface.co/facebook/dinov3-vitl16-pretrain-lvd1689m/blob/main/LICENSE.md) |

| Blender | GPL. Local3D launches the separately installed Blender executable. [Blender license](https://www.blender.org/about/license/) |
